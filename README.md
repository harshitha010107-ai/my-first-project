ABSTRACT

Café Sujes — A Digital Café Menu App

Café Sujes is a Flutter-based digital café menu application developed using Flutter and Dart. The main objective of this project is to provide customers with a convenient and user-friendly platform to explore café menu items and simplify the food selection process. The application features an attractive interface with a coffee-inspired theme, categorized menu items, product descriptions, and prices.

The application allows users to browse different categories, including coffee, tea, desserts, and snacks. It aims to improve the traditional menu-browsing experience by presenting information in a visually appealing and organized manner. The app is designed with a responsive layout to provide a consistent user experience across supported devices.

The current version focuses on the front-end design and menu-browsing functionality. It can be further enhanced by implementing features such as search, shopping cart management, quantity adjustment, order total calculation, and online ordering. Future improvements may include database integration, user authentication, payment gateways, and real-time order tracking.

In conclusion, Café Sujes demonstrates how Flutter and Dart can be used to develop an interactive and aesthetically pleasing café menu application that offers a foundation for a more comprehensive digital ordering system.
